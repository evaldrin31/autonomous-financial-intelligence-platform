## Usage

1. **Engineers**: Start with company/Engineering_Handbook.md
2. **OpenCode**: Follow prompts/MASTER_INSTRUCTIONS.md
3. **Tasks**: Use playbooks/ for step-by-step guidance
4. **Code**: Follow standards/ for consistency

The EOS integrates with:
