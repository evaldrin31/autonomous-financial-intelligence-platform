# Sprint Workflow: AFIP

**Version**: 1.0

## Sprint Cycle

1 week sprints, starting Monday.

## Weekly Rhythm

| Day | Activity | Time |
|-----|----------|------|
| Monday | Sprint Planning | 1 hour |
| Daily | Async Standup | 15 min |
| Wednesday | Mid-sprint check | 30 min |
| Friday | Sprint Review | 1 hour |
| Friday | Retrospective | 30 min |

## Sprint Planning

1. Review backlog
2. Estimate stories (story points)
3. Assign owners
4. Set sprint goal
5. Update board

## Async Standup

Post in #dev-updates:
- What I completed yesterday
- What I'm working on today
- Blockers (if any)

## Story States

```
Backlog → Ready → In Progress → Code Review → Testing → Done
            ↑_________________↓               ↓
                Blocked                    Failed
```

## Estimation

Use Fibonacci: 1, 2, 3, 5, 8, 13

- 1 = 1 hour
- 2 = 1/2 day
- 3 = 1 day
- 5 = 2-3 days
- 8 = 1 week
- 13 = Split it

## Velocity

Track story points completed per sprint.
Average last 3 sprints = velocity.

## Tools

- GitHub Projects for board
- GitHub Issues for tasks
- Discord for async updates
