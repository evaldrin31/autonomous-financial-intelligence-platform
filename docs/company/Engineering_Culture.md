# Engineering Culture: AFIP

**Version**: 1.0

## Values

### 1. Psychological Safety

- Admit mistakes without fear
- Ask questions freely
- Disagree respectfully
- Learn from failures

### 2. Continuous Improvement

- Always be learning
- Seek feedback
- Experiment safely
- Share knowledge

### 3. Ownership

- Own your work
- Fix what you break
- Finish what you start
- Support your team

### 4. Excellence

- Do it right, not fast
- Ship quality code
- Care about craft
- Pride in work

### 5. Collaboration

- Help others succeed
- Share credit
- Document decisions
- Over-communicate

## Team Norms

### Communication

- Async by default
- Sync when needed
- Document everything
- Respect time zones

### Meetings

- Agenda required
- Start on time
- End on time
- Action items documented

### Code Reviews

- Kind, specific, useful
- Learn, don't criticize
- Respond within 4 hours
- Unblock quickly

### Remote Work

- Results over hours
- Trust by default
- Communicate availability
- Boundaries respected

## Growth

- Monthly 1:1s
- Quarterly goals
- Annual reviews
- Learning budget

## Fun

- Virtual coffee
- Show and tells
- Hack days
- Team celebrations
