# Definition of Done: AFIP

**Version**: 1.0

## Universal Criteria

Every task must satisfy:

- [ ] Code written and reviewed
- [ ] Tests passing (>80% coverage)
- [ ] Documentation updated
- [ ] No lint errors
- [ ] Type-safe (no any)
- [ ] Committed to feature branch
- [ ] PR created and approved
- [ ] Merged to develop
- [ ] Staging deployment verified
- [ ] No console errors

## By Task Type

### Feature
- [ ] Requirements met
- [ ] API documented
- [ ] Frontend implemented
- [ ] Integration tested
- [ ] User-facing docs updated

### Bug Fix
- [ ] Root cause identified
- [ ] Fix addresses root cause
- [ ] Regression test added
- [ ] Fix verified in staging

### Refactor
- [ ] No behavior change
- [ ] Tests still pass
- [ ] Performance improved or maintained
- [ ] Code cleaner

### Documentation
- [ ] Accurate
- [ ] Links work
- [ ] Formatted correctly
- [ ] Reviewed

## Review Checklist

- [ ] Logic is correct
- [ ] Code is readable
- [ ] Edge cases handled
- [ ] Errors handled
- [ ] Security considered
- [ ] Performance acceptable
