# Documentation Standards: AFIP

**Version**: 1.0

## Structure

```markdown
# Title

**Version**: 1.0
**Last Updated**: YYYY-MM-DD

## Overview

Brief description.

## Sections

Content here.

## Document Information

| Field | Value |
|-------|-------|
| ID | DOC-XXX |
| Version | 1.0 |
| Owner | Name |

## References

- [Link](./file.md)
```

## Style

- Use headers for structure
- Use tables for data
- Use code blocks for code
- Use lists for steps
- Keep paragraphs short

## Links

```markdown
[Text](./file.md)
[Text](URL)
[Text](../folder/file.md)
```

## Tables

```markdown
| Col1 | Col2 |
|------|------|
| A    | B    |
| C    | D    |
```

## Code

```markdown
Inline: `code`

Block:
```python
def function():
    pass
```
```

## Diagrams

Use Mermaid for diagrams.

## Review

- Update with code changes
- Check links quarterly
- Remove stale content
