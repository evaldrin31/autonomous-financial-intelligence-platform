# Database Standards: AFIP

**Version**: 1.0

## Schema

### Naming

- Tables: snake_case, plural
- Columns: snake_case
- Indexes: idx_tablename_column
- Constraints: meaningful names

### Types

```sql
-- Use appropriate types
id: UUID PRIMARY KEY
created_at: TIMESTAMP WITH TIME ZONE
amount: NUMERIC(19,4) -- For money
quantity: NUMERIC(19,8) -- For crypto
is_active: BOOLEAN DEFAULT TRUE
```

## Models

```python
class Portfolio(Base):
    __tablename__ = "portfolios"
    
    id: Mapped[UUID] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(255))
    created_at: Mapped[datetime]
    
    # Relationships
    user: Mapped["User"] = relationship(back_populates="portfolios")
```

## Queries

```python
# Use async sessions
async with get_db() as db:
    result = await db.execute(
        select(Portfolio).where(Portfolio.user_id == user_id)
    )
    return result.scalars().all()
```

## Migrations

```bash
# Create
alembic revision --autogenerate -m "description"

# Review
# Always review autogenerated migrations before applying

# Apply
alembic upgrade head

# Rollback
alembic downgrade -1
```

## Indexing

```sql
-- Index frequently queried columns
CREATE INDEX idx_portfolios_user_id ON portfolios(user_id);

-- Composite indexes
CREATE INDEX idx_transactions_portfolio_timestamp 
ON transactions(portfolio_id, timestamp);
```

## Anti-patterns

- ❌ SELECT *
- ❌ N+1 queries
- ❌ No indexes on foreign keys
- ❌ Storing money as float
- ❌ Modifying existing migrations
