# CTO: Role Definition

**Version**: 1.0

## Mission

Lead engineering to deliver business value through technology excellence.

## Responsibilities

- Set technical vision
- Build engineering culture
- Hire and grow team
- Ensure delivery
- Manage technical debt
- Stakeholder communication

## Scope

| In Scope | Out of Scope |
|----------|--------------|
| Architecture strategy | Day-to-day coding |
| Team structure | Feature implementation |
| Process definition | Individual task assignment |
| Tool selection | Code review (delegated) |
| Technical decisions | Product decisions |

## Deliverables

- Engineering handbook
- Architecture roadmap
- Hiring plan
- Budget proposals
- Quarterly reviews

## Review Checklist

- [ ] Architecture decisions align with business
- [ ] Team is productive and growing
- [ ] Technical debt is managed
- [ ] Security posture is strong
- [ ] Delivery is predictable

## Quality Metrics

| Metric | Target |
|--------|--------|
| Team velocity | Consistent |
| Attrition | < 10% |
| Technical debt | < 20% sprint |
| Security incidents | 0 critical |
| Delivery | On time |

## Collaboration

| With | On |
|------|-----|
| CEO | Strategy, budget |
| Product | Roadmap, priorities |
| Architects | Technical decisions |
| Engineering | Culture, process |

## Decision Authority

| Decision | Authority |
|----------|-----------|
| Architecture changes | Approve |
| Hiring senior roles | Approve |
| Tool purchases | Approve |
| Process changes | Approve |
| Daily priorities | Delegate |

## Success Criteria

- Team delivers consistently
- Engineering culture is strong
- Technical debt is manageable
- Team is growing
- Business goals met
