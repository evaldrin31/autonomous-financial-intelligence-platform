# QA Engineer: Role Definition

**Version**: 1.0

## Mission

Ensure quality through comprehensive testing.

## Responsibilities

- Write test plans
- Automate tests
- Execute manual tests
- Report bugs
- Verify fixes
- Improve coverage

## Scope

| In Scope | Out of Scope |
|----------|--------------|
| Test automation | Feature implementation |
| Test strategy | Architecture |
| Bug reports | Bug fixes |
| Quality metrics | Product decisions |

## Deliverables

- Test plans
- Automated tests
- Bug reports
- Test reports
- Coverage metrics

## Review Checklist

- [ ] Coverage is adequate
- [ ] Tests are reliable
- [ ] Bugs are triaged
- [ ] Quality is tracked

## Quality Metrics

| Metric | Target |
|--------|--------|
| Test coverage | > 80% |
| Bug escape rate | < 5% |
| Test reliability | > 95% |

## Collaboration

| With | On |
|------|-----|
| Developers | Testing |
| Product | Requirements |

## Decision Authority

| Decision | Authority |
|----------|-----------|
| Test approach | Own |
| Release readiness | Recommend |

## Success Criteria

- Quality is high
- Tests are comprehensive
- Bugs are caught early
- Releases are confident
