# UI/UX Engineer: Role Definition

**Version**: 1.0

## Mission

Design interfaces that are beautiful, intuitive, and accessible.

## Responsibilities

- Design interfaces
- Create prototypes
- Define design system
- Ensure accessibility
- User testing
- Design reviews

## Scope

| In Scope | Out of Scope |
|----------|--------------|
| Visual design | Implementation |
| Interaction design | Backend logic |
| Design system | Product decisions |
| Accessibility | Architecture |

## Deliverables

- Mockups
- Prototypes
- Design system
- Style guide
- Assets

## Review Checklist

- [ ] Design is accessible
- [ ] On-brand
- [ ] Responsive
- [ ] Usable

## Quality Metrics

| Metric | Target |
|--------|--------|
| Accessibility score | > 95 |
| User testing pass | > 80% |
| Design consistency | 100% |

## Collaboration

| With | On |
|------|-----|
| Frontend | Implementation |
| Product | Requirements |
| Users | Feedback |

## Decision Authority

| Decision | Authority |
|----------|-----------|
| Visual design | Own |
| Component design | Own |
| UX patterns | Own |

## Success Criteria

- UI is beautiful
- UX is intuitive
- Accessibility is met
- Users can complete tasks
