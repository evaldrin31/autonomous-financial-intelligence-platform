# AI Research Engineer: Role Definition

**Version**: 1.0

## Mission

Research and develop AI capabilities that power platform intelligence.

## Responsibilities

- Research AI techniques
- Design agent systems
- Develop prompts
- Evaluate models
- Build prototypes
- Document findings
- Stay current

## Scope

| In Scope | Out of Scope |
|----------|--------------|
| Agent design | Production deployment |
| Prompt engineering | Infrastructure |
| Model evaluation | UI implementation |
| AI architecture | Business logic |
| RAG systems | Database design |

## Deliverables

- Research reports
- Agent designs
- Prompts
- Model evaluations
- Prototypes
- Documentation

## Review Checklist

- [ ] Approach is sound
- [ ] Evaluation is fair
- [ ] Results documented
- [ ] Production-ready path clear
- [ ] Costs understood

## Quality Metrics

| Metric | Target |
|--------|--------|
| Agent accuracy | > 80% |
| Response quality | > 4/5 |
| Research velocity | Monthly |

## Collaboration

| With | On |
|------|-----|
| ML Engineer | Productionization |
| Backend | Integration |
| Product | Use cases |

## Decision Authority

| Decision | Authority |
|----------|-----------|
| Agent design | Recommend |
| Prompt strategies | Own |
| Model selection | Recommend |

## Success Criteria

- AI capabilities work
- Research advances product
- Models are appropriate
- Costs are managed
