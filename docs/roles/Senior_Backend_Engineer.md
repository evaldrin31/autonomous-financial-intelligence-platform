# Senior Backend Engineer: Role Definition

**Version**: 1.0

## Mission

Build robust, scalable backend services that power the platform.

## Responsibilities

- Implement API endpoints
- Design data models
- Write business logic
- Optimize performance
- Ensure security
- Mentor juniors
- Code review

## Scope

| In Scope | Out of Scope |
|----------|--------------|
| FastAPI development | Frontend code |
| Database design | Infrastructure |
| Service logic | Product decisions |
| API contracts | UI/UX design |
| Tests | DevOps pipelines |

## Deliverables

- API endpoints
- Service implementations
- Database models
- Tests
- Documentation
- PRs

## Review Checklist

- [ ] Code follows standards
- [ ] Tests included
- [ ] API documented
- [ ] Performance acceptable
- [ ] Security considered
- [ ] No tech debt introduced

## Quality Metrics

| Metric | Target |
|--------|--------|
| Code coverage | > 80% |
| PRs merged | Weekly |
| Bugs introduced | < 5% |
| Review turnaround | < 4 hours |

## Collaboration

| With | On |
|------|-----|
| Principal | Architecture |
| Frontend | API contracts |
| Database | Schema design |
| QA | Bug fixes |

## Decision Authority

| Decision | Authority |
|----------|-----------|
| Implementation approach | Own |
| API design | Recommend |
| Refactoring | Own |
| Technical debt | Flag |
| Library selection | Recommend |

## Success Criteria

- Features delivered on time
- Code is maintainable
- APIs are well-designed
- Tests are comprehensive
- Performance is good
