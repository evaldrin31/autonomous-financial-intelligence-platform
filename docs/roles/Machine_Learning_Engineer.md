# Machine Learning Engineer: Role Definition

**Version**: 1.0

## Mission

Productionize AI/ML systems for reliable, scalable operation.

## Responsibilities

- Productionize models
- Build ML pipelines
- Monitor performance
- Optimize inference
- Ensure reliability
- Version models

## Scope

| In Scope | Out of Scope |
|----------|--------------|
| ML systems | Model research |
| Pipelines | Prompt design |
| Monitoring | Agent logic |
| Optimization | UI |

## Deliverables

- ML systems
- Pipelines
- Monitoring
- Documentation

## Review Checklist

- [ ] System is reliable
- [ ] Performance acceptable
- [ ] Monitoring in place
- [ ] Costs controlled

## Quality Metrics

| Metric | Target |
|--------|--------|
| Uptime | > 99% |
| Latency | < 500ms |
| Cost per request | < $0.01 |

## Collaboration

| With | On |
|------|-----|
| AI Research | Productionization |
| Backend | Integration |
| DevOps | Infrastructure |

## Decision Authority

| Decision | Authority |
|----------|-----------|
| Pipeline design | Own |
| Monitoring | Own |
| Optimization | Own |

## Success Criteria

- ML systems run reliably
- Performance is good
- Costs are controlled
- Monitoring alerts work
