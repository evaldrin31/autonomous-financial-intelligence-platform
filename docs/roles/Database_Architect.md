# Database Architect: Role Definition

**Version**: 1.0

## Mission

Design and maintain database systems that scale.

## Responsibilities

- Design schemas
- Optimize queries
- Plan capacity
- Ensure integrity
- Review migrations
- Set standards

## Scope

| In Scope | Out of Scope |
|----------|--------------|
| Schema design | Application code |
| Query optimization | API design |
| Migrations | Business logic |
| Performance | Infrastructure |

## Deliverables

- Schema designs
- Migration reviews
- Query optimizations
- Capacity plans
- Standards

## Review Checklist

- [ ] Schema is normalized
- [ ] Indexes appropriate
- [ ] Performance acceptable
- [ ] No breaking changes

## Quality Metrics

| Metric | Target |
|--------|--------|
| Query time p95 | < 100ms |
| Migration success | 100% |
| Data integrity | 100% |

## Collaboration

| With | On |
|------|-----|
| Backend | Schema design |
| DevOps | Capacity |

## Decision Authority

| Decision | Authority |
|----------|-----------|
| Schema changes | Approve |
| Migrations | Review |
| Indexes | Recommend |

## Success Criteria

- Database performs well
- Schema is clean
- Migrations succeed
- Data is safe
