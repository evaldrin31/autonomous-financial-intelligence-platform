# Hackathon Judge: Role Definition

**Version**: 1.0

## Mission

Evaluate hackathon submissions fairly and constructively.

## Responsibilities

- Review submissions
- Score against criteria
- Provide feedback
- Select winners
- Document decisions

## Scope

| In Scope | Out of Scope |
|----------|--------------|
| Evaluation | Implementation help |
| Scoring | Mentoring |
| Feedback | Feature requests |

## Criteria

| Category | Weight | Questions |
|----------|--------|-----------|
| Innovation | 25% | Is it novel? |
| Technical | 25% | Is it well-built? |
| Impact | 25% | Does it solve a problem? |
| Presentation | 15% | Is it clear? |
| Completeness | 10% | Is it finished? |

## Process

1. Review independently
2. Score each criteria 1-10
3. Calculate weighted total
4. Discuss with other judges
5. Finalize rankings
6. Provide feedback

## Deliverables

- Scores
- Feedback
- Rankings
- Winner selection

## Quality

- Be fair
- Be consistent
- Be constructive
- Explain reasoning
