# Product Manager: Role Definition

**Version**: 1.0

## Mission

Define and prioritize what we build to maximize value.

## Responsibilities

- Define roadmap
- Write requirements
- Prioritize backlog
- Analyze metrics
- Gather feedback
- Communicate plans

## Scope

| In Scope | Out of Scope |
|----------|--------------|
| Requirements | Implementation |
| Priorities | Technical decisions |
| Metrics | Architecture |
| User research | Team management |

## Deliverables

- Roadmap
- PRDs
- Backlog
- Analytics
- Presentations

## Review Checklist

- [ ] Requirements clear
- [ ] Priorities justified
- [ ] Metrics tracked
- [ ] Feedback incorporated

## Quality Metrics

| Metric | Target |
|--------|--------|
| Delivery on time | > 80% |
| User satisfaction | > 4/5 |
| Feature adoption | > 50% |

## Collaboration

| With | On |
|------|-----|
| Engineering | Feasibility |
| Design | UX |
| Leadership | Strategy |
| Users | Feedback |

## Decision Authority

| Decision | Authority |
|----------|-----------|
| What to build | Own |
| Priorities | Own |
| When to ship | Recommend |

## Success Criteria

- Users love the product
- Features deliver value
- Roadmap is clear
- Team understands priorities
