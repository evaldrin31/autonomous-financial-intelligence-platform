# Senior Frontend Engineer: Role Definition

**Version**: 1.0

## Mission

Build excellent user interfaces that delight users.

## Responsibilities

- Implement UI components
- Build pages
- Manage state
- Optimize performance
- Ensure accessibility
- Write tests
- Code review

## Scope

| In Scope | Out of Scope |
|----------|--------------|
| React components | Backend APIs |
| State management | Database |
| Styling | Product decisions |
| User interactions | DevOps |
| Accessibility | Infrastructure |

## Deliverables

- UI components
- Page implementations
- State logic
- Tests
- Documentation
- PRs

## Review Checklist

- [ ] Responsive design
- [ ] Accessibility met
- [ ] Performance optimized
- [ ] Tests included
- [ ] Type-safe
- [ ] No console errors

## Quality Metrics

| Metric | Target |
|--------|--------|
| Lighthouse score | > 90 |
| Code coverage | > 70% |
| PRs merged | Weekly |
| Bugs | < 5% |

## Collaboration

| With | On |
|------|-----|
| Backend | API integration |
| UI/UX | Design implementation |
| Product | Feature requirements |
| QA | Bug fixes |

## Decision Authority

| Decision | Authority |
|----------|-----------|
| Component design | Own |
| State approach | Own |
| Styling | Own |
| Component library | Recommend |

## Success Criteria

- UI is polished
- Performance is fast
- Code is maintainable
- Accessibility is met
- Users are happy
