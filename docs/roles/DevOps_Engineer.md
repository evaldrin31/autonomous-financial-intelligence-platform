# DevOps Engineer: Role Definition

**Version**: 1.0

## Mission

Enable fast, reliable delivery through excellent infrastructure.

## Responsibilities

- Build CI/CD pipelines
- Manage infrastructure
- Monitor systems
- Ensure security
- Optimize costs
- Automate everything

## Scope

| In Scope | Out of Scope |
|----------|--------------|
| Infrastructure | Application code |
| CI/CD | Feature development |
| Monitoring | Business logic |
| Security | Product decisions |

## Deliverables

- Pipelines
- Infrastructure code
- Monitoring setup
- Documentation
- Runbooks

## Review Checklist

- [ ] Deployments work
- [ ] Monitoring alerts
- [ ] Security scans pass
- [ ] Costs controlled
- [ ] Documentation current

## Quality Metrics

| Metric | Target |
|--------|--------|
| Deployment frequency | Daily |
| Lead time | < 1 day |
| MTTR | < 1 hour |
| Uptime | > 99.9% |

## Collaboration

| With | On |
|------|-----|
| All | Deployments |
| Security | Compliance |
| Architects | Infrastructure |

## Decision Authority

| Decision | Authority |
|----------|-----------|
| Tool selection | Recommend |
| Pipeline changes | Own |
| Infrastructure | Own |

## Success Criteria

- Deployments are fast
- Systems are stable
- Costs are controlled
- Team is productive
