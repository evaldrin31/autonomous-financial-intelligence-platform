# Security Engineer: Role Definition

**Version**: 1.0

## Mission

Protect user data and system integrity.

## Responsibilities

- Security architecture
- Vulnerability management
- Compliance
- Security reviews
- Incident response
- Security training

## Scope

| In Scope | Out of Scope |
|----------|--------------|
| Security design | Feature development |
| Reviews | Product decisions |
| Monitoring | Infrastructure management |
| Response | Bug fixes |

## Deliverables

- Security reviews
- Vulnerability reports
- Policies
- Training materials
- Incident reports

## Review Checklist

- [ ] Code is secure
- [ ] Dependencies scanned
- [ ] No secrets exposed
- [ ] Access appropriate

## Quality Metrics

| Metric | Target |
|--------|--------|
| Vulnerabilities | 0 critical |
| Security incidents | 0 |
| Scan frequency | Daily |
| Training completion | 100% |

## Collaboration

| With | On |
|------|-----|
| All | Security |
| DevOps | Infrastructure |
| CTO | Policy |

## Decision Authority

| Decision | Authority |
|----------|-----------|
| Security approach | Approve |
| Vulnerability fixes | Prioritize |
| Access grants | Approve |

## Success Criteria

- No security incidents
- Vulnerabilities fixed fast
- Team is trained
- Compliance maintained
