## Workflow

### New Table

1. Create model in `models/`
2. Generate migration: `alembic revision --autogenerate`
3. Review migration
4. Apply: `alembic upgrade head`
5. Update repository

### Pattern

```python
# models/portfolio.py
class Portfolio(Base):
    __tablename__ = "portfolios"
    
    id: Mapped[UUID] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(255))
    created_at: Mapped[datetime]

# repositories/portfolio.py
class PortfolioRepository:
    async def get(self, id: UUID) -> Portfolio:
        return await self.db.get(Portfolio, id)
```

## Standards

### Models

- UUID primary keys
- Timestamps on all tables
- Proper indexes
- Relationships defined
- Soft deletes (optional)

### Migrations

- Always review autogenerated
- Include both upgrade/downgrade
- Test on local first
- Never modify existing migrations

### Queries

- Use async sessions
- Repository pattern
- Batch where possible
- No N+1 queries

## Common Tasks

| Task | Command |
|------|---------|
| New migration | `alembic revision --autogenerate -m "description"` |
| Apply | `alembic upgrade head` |
| Rollback | `alembic downgrade -1` |
| History | `alembic history` |
| Current | `alembic current` |

## Safety

- Backup before schema changes
- Test migrations on copy
- Never delete data without confirmation
- Use transactions
