# How To: Create New Milestone

**Version**: 1.0

## Overview

Create and manage development milestones.

## Steps

### 1. Plan

- Define scope
- Set dates
- Identify dependencies
- Assign owners

### 2. Create in GitHub

1. Go to GitHub Projects
2. Create new milestone
3. Set title: "Milestone X: Description"
4. Set due date
5. Add description

### 3. Create Issues

Break milestone into issues:
- Feature issues
- Bug fixes
- Technical debt
- Documentation

### 4. Estimate

Use story points:
- 1: 1 hour
- 2: Half day
- 3: Full day
- 5: 2-3 days
- 8: Full week

### 5. Assign

Assign owners:
- Each issue has owner
- Balanced workload
- Clear dependencies

### 6. Track

Weekly review:
- Progress vs plan
- Blockers
- Scope adjustments

## Template

```markdown
# Milestone X: Name

**Duration**: Weeks N-M
**Status**: Planned

## Goal
One sentence description.

## Deliverables
- [ ] Feature A
- [ ] Feature B
- [ ] Documentation

## Dependencies
- Milestone Y (complete)
```
